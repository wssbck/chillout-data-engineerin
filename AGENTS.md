# Agent instructions

## Changelog

The release history is contained in `CHANGELOG.md`.

- Releases are dated `YYYYMMDD`, newest first.
- Released sections are immutable. Never edit them, not even to fix a typo.
- Record new changes in a new section dated with the day they are released, placed at the top of the list.
- Tags: `[ICEBERG]` marks changes to the Iceberg project in `/iceberg`; `[GENERAL]` marks changes useful beyond it.
